Project name :
FitLog – Workout Library & Planner.

Short description:
FitLog is a modern workout management website where users can explore exercises, view detailed workout information, create a personalized workout plan, save workouts for later, and manage their fitness routine through a responsive and dynamic interface.

Technologies:
Next.js | React | JavaScript | Tailwind CSS | DaisyUI | API | Html | CSS

Minimum 5 features:
1.Workout Library – Browse workouts with images, categories, duration, calories, and ratings.
2.Dynamic Workout Details – View complete information and instructions for each workout.
3.My Plan – Add workouts to today's personalized workout plan.
4.Save for Later – Save favorite workouts and manage them from the Saved section.
5.Mark as Done – Complete workouts and automatically remove them from the active plan.
6.Remove Workout – Remove workouts from both My Plan and Saved sections.
7.Toast Notifications – Get instant notifications when adding, saving, completing, or removing workouts.
8.Responsive Design – Fully responsive interface for desktop, tablet, and mobile devices.
